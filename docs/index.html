Everything you need

Your editor, your scripts and your agents on one side; your coauthors in the browser on the other.

👥

Coauthors Change Nothing

They keep editing, commenting and compiling in the Overleaf web editor. You pull, edit locally and push to the same project.

🆓

Free Plan and Self-Hosted

Checked on a free overleaf.com account. Works on self-hosted Community Edition with olcli config set-url. No git token needed.

🔑

Browser Sign-In

olcli auth --browser works with SSO, Google, ORCID and two-factor logins and keeps only the session cookie. Or paste the cookie at a hidden prompt.

🔄

Pull, Push, Sync, Diff

Diff against the live project before you push, so a coauthor's newer edit shows up first. --exit-code turns it into a CI gate.

📝

Marked-Up Revisions

olcli diff --latexdiff --pdf builds the struck-through and underlined PDF advisors and journals ask for, compiled on Overleaf.

💬

Comments and Tracked Changes

List, add, reply to and resolve comments. Accept or reject tracked changes in projects whose owner has an Overleaf premium plan.

🤖

MCP Server, Asks First

Claude Code, Codex and Cursor can read and edit your projects. Every tool that writes shows what it will do and waits for your confirmation.

🔀

Native Git Remote

git clone overleaf::<url> uses Overleaf as a standard git remote. Clone, commit and push with the commands you already know.

📄

Remote Compilation

Compile on Overleaf's servers, download the PDF or outputs such as .bbl for arXiv. No local TeX installation needed.

Common workflows

🔑 First run

Sign in through a browser window, or paste the session cookie at a hidden prompt.

olcli auth --browser
olcli auth --cookie
olcli auth status

🏢 Self-hosted Overleaf

Set the URL of your Community Edition instance once.

olcli config set-url https://latex.example.org
olcli config set-cookie-name overleaf.sid
olcli auth --browser

📝 Daily thesis work

Edit locally, check what changed on Overleaf, sync and compile.

olcli pull "PhD Thesis" thesis
vim thesis/chapters/results.tex
olcli diff
olcli sync
olcli pdf -o draft.pdf

🖍️ Revision for your advisor

Mark your local revision up inside the document and compile it on Overleaf.

olcli diff --latexdiff --pdf

🔀 Git clone & push

Use Overleaf as a native git remote, without a git token.

git clone overleaf::https://www.overleaf.com/project/abc123
cd abc123
vim main.tex
git commit -am "edits"
git push

📮 arXiv submission

Download compiled artifacts and package for upload.

olcli output bbl -o main.bbl
olcli zip -o arxiv-submission.zip

💾 Backup all projects

One-liner to archive every project as a zip.

olcli list --json | jq -r '.[].name' \
| xargs -I{} olcli zip "{}" -o "{}.zip"
